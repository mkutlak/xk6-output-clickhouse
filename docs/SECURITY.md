# Security Policy

## Supported versions

Only the latest release receives security fixes. The project is pre-1.0, so fixes land in a new minor or patch release rather than being backported.

## Reporting a vulnerability

Do not open a public issue. Report it privately through GitHub instead:
[Report a vulnerability](https://github.com/mkutlak/xk6-output-clickhouse/security/advisories/new).

Include the affected version, how to reproduce the problem, and its impact (for example, ClickHouse credentials or TLS key material exposed in logs, or TLS verification bypassed). Follow-up happens in the private advisory thread, and the fix is disclosed there once a release ships it.
